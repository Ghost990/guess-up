# Hoppra recap poster export

The recap PNG is a 1080 x 1350 flat party-print poster, rendered entirely with browser Canvas 2D primitives.

- **Paper and ink:** off-white stock, warm-black outlines, and coral, cyan, yellow, and mint spot colors. Offset shapes provide the print character. No gradients, emoji, stock artwork, or external assets are used.
- **Hierarchy:** a hand-drawn trophy and ribbon frame the winner as the primary moment. First through third receive progressively smaller leaderboard rows; up to six total players remain inside the same bounded standings area.
- **Resilience:** single-line winner and player labels use deterministic end truncation based on Canvas measurements. Score columns stay fixed and never collide with names.
- **Signature:** compact game counts sit in one ticker-style band and the Hoppra wordmark closes the composition.
